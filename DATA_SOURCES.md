# Data sources and reuse notes

## Dataset

**EEGLAB STERN tutorial study** — a Sternberg working-memory experiment
distributed for EEGLAB STUDY tutorials.

Official sources:

- https://eeglab.org/tutorials/tutorial_data.html
- https://eeglab.org/tutorials/10_Group_analysis/working_with_study_designs.html
- https://sccn.ucsd.edu/eeglab/download/STUDYstern_125hz.zip

## Local subset

- Participants: S01–S13
- Conditions: Ignore, Memorize, Probe
- EEGLAB `.set` datasets: 39
- Approximate extracted size: 1.1 GB
- Sampling rate: 125 Hz
- Epoch interval: −1.000 to 1.992 s
